# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting for this repository:

<https://github.com/designdelulu/explosion-dynamics-lab/security/advisories/new>

Include the affected browser or platform, reproduction steps, expected and
actual behavior, and any relevant console or network evidence. Do not include
credentials, private user data, or destructive proof-of-concept payloads.

## Scope

Security reports may cover the browser application, export pipeline, vendored
FFmpeg WebAssembly integration, production build tooling, content security, or
dependency provenance. General rendering bugs and feature requests belong in
the public issue tracker.

Only the latest public release is supported. Because this project is a static
client-side application, fixes are normally delivered through a new
content-addressed release.
